# 🔨 ДЕМОНТАЖ-ПРО — Демонтажные работы в квартирах и домах

Конверсионный одностраничный сайт под ключ для услуг по сносу стен, перегородок, демонтажу стяжки и вывозу мусора с интерактивным калькулятором сметы.

🌐 **Демо онлайн:** [https://garipov-ar.github.io/demolition-service/](https://garipov-ar.github.io/demolition-service/)

## 🛠 Стек технологий
- **Next.js 15 (App Router)** + **React 19** + **TypeScript**
- **CSS Modules**, адаптивная верстка (Mobile First)
- **Lucide React** иконки
- **GitHub Actions** автоматический CI/CD деплой на GitHub Pages

## 🚀 Возможности
- Интерактивный калькулятор стоимости: расчет по площади пола, сносу стен (гипсокартон / кирпич / бетон), демонтажу стяжки и заказу контейнера 8м³.
- Прозрачный прайс-лист на все виды работ.
- Аккордеон с частыми вопросами (FAQ).
